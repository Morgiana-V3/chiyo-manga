# 千代 · Chiyo Manga

面向 AI 辅助黑白日式漫画的 Electron 桌面编辑器。第一版聚焦单页制作、具体参考素材和前台可见的 MCP 协作。使用 Vue 3、TypeScript、Less；故事蓝本拆解留待后续版本。

## 运行

需要 Node.js 22.12+（建议当前 LTS），Windows 开发环境。

```powershell
npm ci
npm run dev
```

真实生图使用已运行的 **NovelPrompt 开发实例**，沿用其 NovelAI 配置和额度。默认查找同级 `novel-prompt` 仓库和 `%APPDATA%/novel-prompt-dev`；打包版默认查找桌面的 `novel-prompt`。路径不同时，启动前设置 `CHIYO_NOVELPROMPT_ROOT`。不复制密钥，不自动启动或修改 NovelPrompt。连接时核对真实路径、运行模式和数据目录。

## 已实现

- 紧凑的顶部文件/编辑/图层/视图菜单，与窗口控件合并；页面尺寸、DPI、安全边距、四格布局起点。
- 矩形、斜格与可编辑凸多边形格框，横向/纵向/斜向切格与可设格间距；移动、缩放、旋转、图层拖动排序、锁定、显隐、复制、撤销/重做；支持文件夹嵌套、整组调序、展开折叠、继承显隐/锁定和解除分组。
- 导入画稿、按格裁切和出格构图；六种气泡样式、可拖动轮廓与弯尾、连体气泡、文字边距与自动缩字；横排/基础竖排文字、页码、黑白笔画、网点、速度线、集中线。
- 人物、服装、道具、场景、画风、画稿素材；具体图片预览、设定备注、系列版本、候选/采用状态、图层绑定和来源记录。
- NovelAI 单张生成与矩形选区局部重绘，结果先进入素材库；原图与修订版本并存，记录实际请求、操作编号、PNG 和服务端额度变化。
- 前台 MCP 读状态、看真实素材/工作区、导入、展示方案、逐步采纳、编辑、生成、查询操作和导出。与人工共用状态、动作和撤销；用户输入时阻止外部修改。
- `.chiyo` 工程打包图片、自动恢复保存、原尺寸 PNG 导出及 DPI 元数据。

## 推荐工作流程

1. 导入人物/道具/场景参考，在素材详情填写辨识特征，手动指定采用版本。
2. 新建页面，设置尺寸，绘制漫画格。选中格后双击画稿可放入并裁切。
3. 选中漫画格或画稿，将需要遵守的素材“绑定参考”。绑定的是具体版本，新候选不会偷偷替换已使用的图片。
4. 使用生图面板，或让外部 Agent 先看图和提出前台方案。生成结果需查看后再放入画布。
5. 添加对白与效果、检查阅读顺序，保存工程并导出 PNG。

画布导航：滚轮围绕鼠标位置缩放，底部可输入 5%–400% 的比例；空格+左键、中键拖动或 H 抓手工具平移。Ctrl+0 适合窗口，Ctrl+1 实际大小；Shift+滚轮水平平移。导航不改动画稿坐标或撤销历史。

图层：双击名称、F2 或右键菜单可重命名；Enter 提交、Escape 取消。右键支持复制、显隐、锁定、调序、移回根目录、解除分组与删除。拖动使用跟随预览和落点提示，靠近列表边缘时自动滚动，Escape 取消拖动。拖到另一行的上/下缘调整层级，拖到文件夹中部移入，拖到“页面根目录”移出。粉色插入线/文件夹高亮表示目标；也可在属性的“所属文件夹”中选择位置。文件夹最多嵌套 8 层。文件夹和漫画格裁切是独立关系；移动目录保留坐标和裁切。文件夹的删除包含子图层，可撤销；“解除分组，保留内容”只移除目录。

侧栏：拖动画布两侧的细分隔线调整宽度，双击恢复默认宽度；聚焦分隔线后可用左右方向键微调、Home 复位。宽度会保存在本机界面偏好中。画布与素材也提供相应的右键菜单；提示消息悬浮显示，不挤占编辑区域。

复制/粘贴：Ctrl+C 只捕获当前图层（文件夹包含子层，漫画格包含格内内容），切换同一工程内的页面后按 Ctrl+V 按原坐标粘贴。单独复制裁切画稿会带隐藏的裁切参照，保持画面范围。Ctrl+D 才立即创建偏移副本；这些操作也在编辑菜单和图层右键中。缓冲区在重启或切换工程时清空；每次粘贴可一次撤销。

快捷键：V 选择、H 抓手、F 格框、K 切格、N 节点编辑、B 气泡、T 文字、P 黑笔、E 白笔；Ctrl+Z/Y 撤销/重做，Ctrl+S 保存，Ctrl+O 打开。输入框有焦点时保留正常文字编辑行为。旧工程可直接打开；含文件夹的新工程请使用 v0.2 或更新版本。

分格：选中一个格框，按 K，从格框一侧拖到另一侧；上方设置格间距，按住 Shift 限制水平/垂直。切分保留画稿位置并为两格分别裁切，一次撤销恢复。按 N 拖动白色顶点调整格形，节点不能越过对边；需要扩大格框时先用选择工具调整尺寸。

气泡：新气泡默认手绘样式，在属性面板切换椭圆/手绘/思考/喊叫/低语/旁白。按 N 拖动白色轮廓节点、尾尖和金色弯曲点；可添加多条尾巴或带独立对白的连体气泡。自动缩字最低 8 px；仍超出时提示，导出会裁切溢出部分但工程保留原文。旧气泡选择新样式前保持原样。含新几何的工程请使用 v0.4 或更新版本。

## 当前边界

**素材库保证参考可追溯，尚不能保证模型生成外观一致。** 当前 NovelPrompt 的公开 `generate_image` 接口不接收参考图片；绑定素材仅供 Agent 看图与构建提示。存在绑定时，界面要求明确选择“仅传提示词”。不会把这条路径包装成图像参考控制。

局部重绘只支持本项目经 NovelPrompt 生成的原图和矩形选区；它会真实传原图与遮罩。生成失败或结果未知不会自动重试，应先查询原操作。当前没有任意外部图的 NovelAI 重绘导入、参考图条件生成、压力笔刷、PSD/CSP 导入、PDF/印刷色彩管理或自动故事分镜。竖排目前为基础排版，尚无完整日文禁则与注音。

## MCP

打开右侧“AI 协作”→连接图标→复制当前实例配置，交给支持 stdio MCP 的 Agent。需要本机 Node.js。代理只连接正在运行的桌面实例；桌面必须保持打开。

详见 [MCP 契约](docs/mcp.md)、[架构](docs/architecture.md)、[开发与验证](docs/development.md)。
